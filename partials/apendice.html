Sugestões de conteúdos

Para continuar depois do dia.

Leitura recomendada

  • Thinking in Bets — Annie Duke
    Pensar em apostas (Amazon)

    Estrutura o processo de decisão. Annie, ex-jogadora de poker, trata toda decisão como aposta sobre o futuro: sair do binário (certo/errado) e pensar em probabilidade.

  • Thinking in Systems — Donella H. Meadows
    Pensando em sistemas (Amazon)

    Pensamento crítico, analítico e sistêmico. Donella mostra que tudo é um conjunto de sistemas interconectados, não eventos isolados.

  • Product Management OKRs — Tim Herbig
    herbig.co/okrs-product-management-hub

    Hub de artigos e vídeos para ligar estratégia de produto a OKRs de outcome. O texto sobre leading e lagging é o mais próximo do Connect.

Vídeo

  • Exact Instructions Challenge (PB&J) — Josh Darnit
    YouTube

    Referência apresentada no curso: o custo de instruções vagas quando o executor segue ao pé da letra — o mesmo risco ao briefar uma IA.

  • Como ele fez R$ 15 milhões em apenas 48 horas (com Vibe Coding) — Bruno Okamoto
    YouTube

    A resposta ficou barata: o que muda quando construir deixa de ser o gargalo.

Na sala

  • Competição GMAT — dinâmica ao vivo com o Edu
    dinamica-gmat.vercel.app

    Abram quando ele pedir — não antes. Entram com o e-mail; a sala começa junta.

Skills

  • skills.sh

    Diretório aberto de Agent Skills. Instale com npx skills add ….

  • last30days

    Pesquisa um tema nos últimos 30 dias (Reddit, X, YouTube, HN, Polymarket e web) e sintetiza um resumo com fontes.

  • find-skills (Vercel Labs)

    Descobre e instala Agent Skills no ecossistema aberto quando você precisa de uma capacidade nova.

MCPs

MCP é a tomada padrão para plugar ferramenta no agente. Instale pelo Cursor Marketplace ou configure em mcp.json. Docs: cursor.com/docs/mcp.

Diretórios

  • cursor.directory — comunidade (indicado pela Cursor)
  • mcpservers.org
  • MCP Server Space

Sugestões para PMs

  • GitHub MCP — repos, issues e PRs. No Cursor, o GitHub também entra como integração nativa (Settings → Integrations).

  • Vercel MCP — projetos, deploys e logs. Servidor oficial: https://mcp.vercel.com.

  • Google Workspace MCP (Taylor Wilsdon) — Drive, Docs, Sheets, Calendar, Gmail.

  • Databricks MCP — queries e dados no warehouse (docs atualizadas em ago/2026).

O browser do Cursor é nativo (não precisa de MCP separado para abrir a página).
