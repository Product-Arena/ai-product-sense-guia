Publicar o painel (GitHub + Vercel)

Conteúdo adicional depois do Build. O exercício pede um HTML que abre no browser; este caminho coloca esse arquivo num link público — útil para mostrar no time ou guardar o artefato do dia. Não é obrigatório na sala.

Fluxo: o HTML mora no GitHub; a Vercel lê o repositório e publica. Cada push novo atualiza o site.

1. Preparar o arquivo

  1. Tenha o painel salvo no computador (ex.: painel.html baixado do Claude/ChatGPT ou gravado pelo Cursor).
  2. Renomeie para index.html. Assim a URL da Vercel abre o painel na raiz, sem path extra.
  3. Se o painel tiver imagens ou CSSs separados, mantenha tudo na mesma pasta. Um único HTML com CSS inline (como no exercício) é o caminho mais simples.

2. Subir no GitHub

  1. Crie uma conta em github.com (se ainda não tiver).
  2. New repository — nome livre (ex.: painel-arena-cash). Pode ser público ou privado. Não marque “Add a README” se for só colar o HTML depois.
  3. Entre no repositório vazio → Add file → Upload files → arraste o index.html → Commit changes.
  4. No Cursor (opcional): peça para criar o repo, gravar o index.html e dar git push. O resultado é o mesmo.

Não suba chaves, tokens nem dados reais de cliente. Os kits Arena do curso são fictícios e podem ir no repo.

3. Ligar na Vercel

  1. Crie uma conta em vercel.com (login com GitHub é o mais rápido).
  2. Add New… → Project → importe o repositório do painel.
  3. Em Framework Preset, deixe Other (site estático). Não precisa de Build Command nem Output Directory para um HTML na raiz.
  4. Deploy. Em cerca de um minuto aparece uma URL do tipo seu-projeto.vercel.app.

4. Atualizar depois

  1. Edite o HTML (você ou o agente).
  2. No GitHub: Add file → Upload files de novo (substitui o index.html) ou faça commit/push pelo Cursor.
  3. A Vercel detecta o push e publica sozinha. O link continua o mesmo.

Docs oficiais: Importar projeto na Vercel · Quickstart de repositório no GitHub.

MCPs

MCP é a tomada padrão para plugar ferramenta no agente. Instale pelo Cursor Marketplace ou configure em mcp.json. Docs: cursor.com/docs/mcp.

Diretórios

  • cursor.directory — comunidade (indicado pela Cursor)
  • mcpservers.org
  • MCP Server Space

Sugestões para PMs

  • GitHub MCP — repos, issues e PRs. No Cursor, o GitHub também entra como integração nativa (Settings → Integrations).

  • Vercel MCP — projetos, deploys e logs. Servidor oficial: https://mcp.vercel.com.

  • Google Workspace MCP (Taylor Wilsdon) — Drive, Docs, Sheets, Calendar, Gmail.

  • Databricks MCP — queries e dados no warehouse (docs atualizadas em ago/2026).

O browser do Cursor é nativo (não precisa de MCP separado para abrir a página).
