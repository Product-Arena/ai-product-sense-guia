Think

Product Sense e pensamento crítico.

O Edu apresenta o case nos slides. Aqui está o que vocês fazem. Não precisa baixar arquivo nem anexar o kit — na hora da IA, cole o contexto e o prompt abaixo.

01 ~25 min

Objetivo: decidir sobre o onboarding com IA da Arena Pipeline — primeiro de cabeça, depois com um Devil's Advocate. Não anexar arquivos.

Combinados
  1. Ambiente seguro. Não é teste sobre quem sabe mais. A ideia é começar uma prática que pode virar rotina no time.
  2. Perguntem o que não souberem. Não levem dúvida para casa.
  3. Não existe pergunta ruim. Ruim é não perguntar.
  4. A IA entra na tarefa 5, não antes. As quatro primeiras são de cabeça. A comparação com a IA só funciona se vocês tiverem uma resposta própria primeiro.
O case

A Arena Pipeline é um SaaS B2B. O time lançou um novo onboarding com IA para ajudar a configurar o produto e chegar mais rápido ao primeiro valor. Objetivo: aumentar a conversão Free → Paid.

Depois de 30 dias, o PM apresenta:

AntesDepois
Free → Paid3,2%5,1%

Conclusão do PM: “A conversão aumentou 59%. O onboarding com IA funcionou. Vamos expandir para 100% da base.”

1–4 10 min

De cabeça — sem IA

Em grupos, respondam:

  1. O que sabemos?
  2. O que ainda não sabemos?
  3. Qual decisão você tomaria agora?
    (a) Expandir   (b) Não expandir   (c) Ainda não consigo decidir
  4. Qual seu nível de confiança, de 0 a 100?
Info nova 5 min

O PM esqueceu de contar uma coisa

Siga sem IA.

Abrir só quando o Edu pedir — informação nova

Os usuários que receberam o novo onboarding eram de um segmento que historicamente já convertia 4,8%.

  • O que parecia ser: 3,2% → 5,1%, +59%
  • Agora parece ser: 4,8% → 5,1%, +0,3 p.p.

Essa informação nova muda sua decisão? Debatam 5 min. Anotem se a confiança subiu ou desceu.

Prompt

Atue como Devil's Advocate da nossa decisão. Identifique premissas que podemos estar assumindo, perguntas importantes que ainda não fizemos e explicações alternativas para os dados. Não invente fatos ou dados que não estão no case. Se nossa análise estiver bem fundamentada, diga isso também.

O que o Devil's Advocate gerou?

  • A IA encontrou alguma pergunta que vocês não fizeram?

01 ~25 min

Objetivo: construir e testar uma skill de análise crítica no case que vocês escolheram. A saída não é texto de chat — é um painel HTML que dá para reabrir.

Regras
  1. Baixem o case da empresa mais parecida com o negócio de vocês.
  2. Construam a skill no agente, cobrindo os 5 blocos abaixo (é o caminho do dinheiro do Dudu, não um framework novo).
  3. Rodem a skill nos dados do kit. Não inventem número fora do arquivo.
  4. O output final precisa incluir um arquivo HTML navegável — não só texto corrido.
5 blocos

O que a skill precisa considerar

  1. Decisão e tese — uma tese falsificável: “Acreditamos que [intervenção] para [público] mudará [comportamento], gerará [resultado] e contribuirá para [impacto econômico]. Vamos considerar válida quando [critério, prazo, comparação].”
  2. Mapa econômico — qual rota o case ataca: aumentar/preservar receita ou reduzir custo/proteger margem, no modelo da empresa (marketplace, SaaS B2B ou fintech).
  3. Árvore de impacto — Input → Output → Outcome → Impacto, cada métrica rotulada leading ou lagging, e a camada Controle / Influência / Contribuição.
  4. Teste de causalidade — evidência de cada elo, contrafactual, variável de confusão (o mesmo músculo do Think).
  5. Alertas de desvio — o painel sinaliza quando a métrica sai do esperado, não só mostra o número atual.

Travou na skill? Use o O.C.A.R.E.O da manhã como esqueleto (Objetivo, Contexto, Ações, Regras, Exemplos, Output).

3–4 8–9 min

Rodar no case e gerar o HTML

Anexe o kit (ou aponte a pasta). Depois peça o painel. Um único .html com CSS inline — não é projeto de front-end.

Prompt

Use a skill product-sense-money-path (Product Sense · Caminho do dinheiro).

Case: [Arena Match | Arena Pipeline | Arena Cash].

Aplique os 5 blocos. Não invente dado. Se faltar número, marque lacuna.

Em seguida gere UM arquivo HTML (CSS inline, uma página) com:
- Cabeçalho: nome da empresa, data de hoje, a tese em uma frase

- Indicadores: cards com números do kit e badge verde / amarelo / vermelho para os alertas de desvio

Visual simples, legível em projector. Sem dependência externa.
