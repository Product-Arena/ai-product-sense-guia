ANTES DE COMEÇAR

Pré-requisitos

Três coisas antes do dia: uma ferramenta de IA, uma conta Google e uma conta no GitHub.

1
Conta no Claude, ChatGPT ou Cursor basta uma das três — logada e testada antes do dia
Obrigatório

Escolha a que você já usa no trabalho. Se ainda não tem nenhuma, crie a que for mais fácil de acessar no computador que você vai levar.

  1. claude.ai — Sign up / Log in
  2. chatgpt.com — Sign up / Log in
  3. cursor.com — Sign in e, se for usar na sala, o app desktop
2
Conta Googlea mesma que você vai usar no Drive, logada no navegador
Obrigatório

No Track, os CSV da Arena Cash são copiados para o seu Drive. A cópia acontece no exercício, não antes. Se ainda não tiver conta, crie em accounts.google.com/signup.

3
Conta no GitHub logada no navegador antes do dia
Obrigatório

Se ainda não tiver, crie em github.com/signup. No Track, o GitHub pode ser a fonte de contexto do produto (README, hipótese, entregas). Conta criada basta; não precisa instalar o Git nem saber comandos.
